# 경기결과등록 화면 기획

## 목적
- 관리자 화면에서 시즌별 경기결과를 빠르게 입력/수정합니다.
- 경기결과가 등록되면 해당 경기는 자동으로 `경기종료` 상태로 처리합니다.

## 권한
- 조회/수정: `admin`, `super_admin`
- 일반 회원(`member`)은 관리자 화면에 접근할 수 없습니다.

## 화면 구조
- 진입: `시즌 관리 > 시즌 상세 > 경기결과등록`
- 목록: 선택 시즌의 전체 경기를 `월/주차` 단위로 그룹 표시
- 행 정보
  - 일자
  - 경기 팀(`홈팀 vs 원정팀`)
  - 경기 상태(`경기전`, `진행중`, `경기종료`, `취소`)
  - 결과 입력(Home 점수 : Away 점수)

## 입력/저장 규칙
- 점수 입력은 상태와 무관하게 허용합니다.
- 저장 트리거
  - 엔터
  - 포커스 아웃(blur)
- 입력 검증
  - 숫자만 허용
  - 0 이상의 정수만 허용
- 미입력 값은 `-`로 표시합니다.

## 상태 자동 전환 규칙
- `home_score`, `away_score`가 모두 입력되면 `status = 'finished'`
- 두 점수가 모두 비워지면 `status = 'scheduled'`
- `cancelled` 상태 경기는 점수가 없는 경우 유지되며, 점수가 둘 다 입력되면 `finished`로 전환됩니다.

## 데이터 반영 범위
- 결과 저장 시 `matches.home_score`, `matches.away_score`, `matches.status`를 함께 업데이트합니다.
- active 시즌인 경우 홈/일정 화면의 경기결과 표시도 즉시 반영됩니다.
