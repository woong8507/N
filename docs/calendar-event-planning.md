# 통합 캘린더(월간뷰) 기획

## 개요
이 문서는 구글 캘린더 형식의 월간 캘린더를 기준으로, 공휴일/회원 일정/경기 일정을 한 화면에서 관리하는 기준 문서입니다.

관련 문서:

- `docs/menu-planning.md`
- `docs/schema-planning.md`
- `docs/admin-permissions.md`
- `docs/auth-flow.md`

## 목표
1. 월간 캘린더에서 모든 일정 유형을 통합 조회합니다.
2. 경기 데이터 무결성은 기존 시즌 구조(`seasons`, `season_teams`, `matches`)를 유지합니다.
3. 회원 일정 등록은 간단하게, 권한은 명확하게 분리합니다.
4. 한국 공휴일은 연도 단위 자동 동기화를 기본으로 운영합니다.
5. 관리자 시즌 화면에서 월간 캘린더 확인, 일정 등록, 삭제를 한 화면에서 처리합니다.

## 일정 유형
- `holiday`: 한국 공휴일
- `match`: 경기 일정
- `leave`: 휴가
- `business_trip`: 출장
- `personal`: 기타 개인 일정

## 저장 모델
통합 조회 테이블을 `calendar_events`로 정의하고, 경기는 `matches`를 원본으로 유지합니다.

핵심 원칙:
- `match` 이벤트는 `linked_match_id`로 `matches`를 참조합니다.
- 개인 일정은 `calendar_events`에서 직접 관리합니다.
- 공휴일도 `calendar_events`에 저장합니다.

권장 주요 컬럼:
- `id bigserial primary key`
- `season_id bigint null`
- `linked_match_id bigint null`
- `event_type text not null`
- `title text not null`
- `description text`
- `location_floor text`
- `start_at timestamptz not null`
- `end_at timestamptz not null`
- `is_all_day boolean not null default false`
- `created_by uuid`
- `source_type text not null default 'manual'`
- `created_at timestamptz not null default now()`

## 시간 규칙
시간 입력은 `종일 플래그 + 시작/종료 datetime`으로 통일합니다.

- `is_all_day = true`
  - 종일 일정으로 표시
  - DB 제약(`end_at > start_at`)을 만족하기 위해 **KST 기준 12:00 ~ 12:01**로 저장
  - 날짜 이동(UTC 변환) 이슈를 피하기 위해 자정(00:00) 대신 정오(12:00) 앵커 사용
- `is_all_day = false`
  - 시작/종료 시간이 모두 필요
  - `end_at > start_at` 필수

경기(`match`) 규칙:
- 종일 입력 금지 (`is_all_day = false`)
- 시작/종료 시간 필수
- 장소는 `3F`, `4F` 중 선택
- `matches.match_date`는 **KST 기준 정오(12:00)** 앵커로 저장

## KST 기준 정책
- 이 시스템은 한국 사용자 전용 운영을 기준으로 합니다.
- 화면 날짜와 DB 날짜를 동일하게 유지하기 위해 날짜 계산/표시는 KST 기준으로 처리합니다.
- 월간 캘린더 키 생성, 표시 라벨, 충돌 계산은 KST 일자 기준으로 동작합니다.

## 경기 표기 규칙
경기 카드는 아래 형식으로 표기합니다.

- `클럽A vs 클럽B`

표기 원칙:
- 데이터 저장은 `season_teams`, `matches` 참조 기반 유지
- 표기 문자열은 `season_teams` 조인으로 조회한 **Teams(`teams`) 테이블 `name` 필드**를 우선 사용해 생성
- 팀명은 항상 Teams(`teams`) 테이블 `name` 필드 기준으로 노출
- `1팀`, `2팀` 같은 임시 라벨은 표시 기준으로 사용하지 않음
- 문자열 단독 저장을 기준으로 삼지 않음

## 권한 기준
- 공통: 로그인 회원은 캘린더 조회 가능
- 개인 일정(`leave`, `business_trip`, `personal`)
  - 회원 본인 생성/수정/삭제 가능
  - 관리자(`admin`, `super_admin`) 관리 가능
- 경기(`match`)
  - 관리자만 등록/수정/삭제 가능
- 공휴일(`holiday`)
  - 자동 동기화 실행 및 수동 보정/삭제는 관리자만 가능

## 공휴일 동기화 정책
- 데이터 소스: Nager.Date
- 대상 국가: `KR`
- 동기화 단위: 연도
- 실행 주체: 관리자

운영 흐름:
1. 관리자가 대상 연도 선택
2. 공휴일 동기화 실행
3. 해당 연도 공휴일 `upsert`
4. 예외 케이스는 관리자가 수동 보정

## 금일 경기 참석 체크(v1)
목표:
- 회원이 메인 화면에서 본인 선수 카드를 눌러 금일 경기 참석 상태를 빠르게 표시합니다.

동작 기준:
- 클릭 가능 대상은 **KST 기준 금일(오늘) 경기**에 포함된 본인 선수 카드만 허용합니다.
- 금일 경기가 아닌 날짜의 카드는 조회 전용(클릭 비활성)으로 처리합니다.
- 상태는 `미정 -> 참석 -> 불참 -> 미정` 순환 토글을 기본으로 합니다.

표시 기준:
- `참석`: 카드 테두리 강조 + 확인(체크) 아이콘
- `불참`: 경고 색상 테두리 + 불참 아이콘
- `미정`: 기본 카드 스타일

권한 기준:
- 회원은 본인 상태만 수정할 수 있습니다.
- 관리자(`admin`, `super_admin`)는 전체 조회/집계가 가능합니다.

## 입력 항목 기준
### 개인 일정
- 유형(`leave`, `business_trip`, `personal`)
- 제목
- 종일 여부
- 시작/종료
- 메모(선택)

### 경기 일정
- 경기일
- 시작/종료 시간
- 장소(`3F`/`4F`)
- 팀 A, 팀 B
- 각 팀 선수 **1명 이상**
- 팀 라벨은 `팀명 (선수1, 선수2, ...)` 형식으로 노출

### 공휴일
- 자동 동기화로 기본 생성
- 관리자 수동 등록/삭제 가능

## 시즌 운영 화면(관리자) 최신 기준
### 월간 일정 패널
- 필터: `전체`, `경기`, `회원일정`, `공휴일`
- 날짜 선택 시 하단 상세 목록에 일정 표시
- 상세 목록에서 경기/일정 개별 삭제 가능
- 회원 일정은 대상 회원명을 함께 표시

### 일정 등록 패널 (관리자)
- 단일 폼으로 등록 처리
- 입력 순서: `유형 -> 대상 회원 -> 제목 -> 날짜 -> 메모`
- 유형: `공휴일`, `휴가`, `출장`, `기타`
- `공휴일` 선택 시 대상 회원 입력 비활성화
- 공휴일 등록은 관리자 권한에서만 허용

## 경기 등록 차단/경고 규칙
### 1) 공휴일 차단
- 경기일이 공휴일이면 팀 선택 단계에서 차단
- 저장 단계에서도 DB 재확인 후 차단
- 메시지: 공휴일로 인해 경기 등록 불가

### 2) 회원 일정 충돌
- 참여 선수에게 `휴가/출장/기타` 일정이 있으면 충돌로 판단
- 팀 선택 단계에서 해당 팀 선택 차단
- 저장 단계에서는 충돌 안내 후 확인(`그래도 등록`)을 거쳐 진행 가능
